# VMark 入门指南

VMark 是人类与 AI 协作的纯文本工作区。双方直接读写同一份产物 —— Markdown、YAML、JSON、TOML、Mermaid、SVG、HTML、代码 —— 中间没有任何转换层。当文件是已知的产物类型（GitHub Actions 工作流、`Cargo.toml`、`package.json`、`pyproject.toml`）时，VMark 会渲染*恰当*的视图，而不是通用的 JSON 树。

真正的差异不在于"能打开更多文件类型" —— 每个 IDE 都能做到。而在于**感知 schema 的预览**：为每种产物提供结构化视图，并搭配一个实时的源码窗格。

## 快速开始

1. 从[下载页面](/zh-CN/download)**下载并安装** VMark
2. **启动应用**，立即开始写作
3. 使用 **文件 → 打开文件...** 或拖放任意[支持的格式](/zh-CN/guide/formats)来 **打开文件**（`Cmd/Ctrl + O` 是 **快速打开**，用于跳转到最近、已打开或工作区中的文件）
4. 使用 `Cmd/Ctrl + Shift + O` **打开文件夹**，进入工作区模式

## 界面概览

### 主要区域

- **编辑器**：撰写文档的主要写作区域
- **侧边栏**：文件树导航（使用 `Ctrl + Shift + 2` 切换）
- **大纲**：文档结构视图（使用 `Ctrl + Shift + 1` 切换）
- **状态栏**：字数统计、字符统计和自动保存状态（使用 `F7` 切换）
- **终端**：集成的 Shell 面板（使用 `` Ctrl + ` `` 切换）

### 菜单栏

- **文件**：新建、快速打开、最近的文件和工作区、文档历史、保存、导出、打印、关闭
- **编辑**：撤销/重做、剪贴板、查找（包括在文件中查找）、选择、行操作、行尾符、Genies
- **格式**：文本样式、标题、列表、引用块、文本转换、中日韩格式化、文本清理、图片清理
- **插入**：链接、图片、视频、音频、表格、代码块、数学公式、图表、脚注、折叠块、信息框
- **视图**：编辑模式、窗格、侧边栏面板、专注/打字机模式、工具栏、终端、窗口状态、检查 Markdown、缩放
- **窗口**（macOS）：最小化、最大化、一致性明细、将全部窗口置于前方
- **帮助**：VMark 帮助、键盘快捷键、`vmark` Shell 命令（macOS）、报告问题

### 编辑模式

VMark 支持三种编辑模式，可随时切换：

| 模式 | 描述 | 快捷键 |
|------|------|--------|
| 富文本 | 实时格式化的所见即所得编辑 | 默认 |
| 源码 | 带语法高亮的原始 Markdown | `F6` |
| 分屏 | 左侧为源码，右侧为实时只读预览 | `Shift + F6` |

### 视图模式

通过以下视图模式增强写作专注度：

| 模式 | 描述 | 快捷键 |
|------|------|--------|
| 专注 | 高亮当前段落 | `F8` |
| 打字机 | 保持光标居中 | `F9` |
| 自动换行 | 切换折行显示 | `Alt + Z` |

## 基本格式

### 文本样式

| 样式 | 语法 | 快捷键 |
|------|------|--------|
| **粗体** | `**text**` | `Cmd/Ctrl + B` |
| *斜体* | `*text*` | `Cmd/Ctrl + I` |
| ~~删除线~~ | `~~text~~` | `Cmd/Ctrl + Shift + X` |
| `代码` | `` `code` `` | `Cmd/Ctrl + Shift + `` ` `` |

### 块级元素

- **标题**：使用 `#` 符号或 `Cmd/Ctrl + 1-6`
- **列表**：以 `-`、`*`、`1.` 或 `- [ ]`（任务列表）开头
- **引用块**：以 `>` 开头，或使用 `Alt/Option + Cmd + Q`
- **代码块**：使用三个反引号，可选指定语言
- **表格**：使用 **插入 → 表格** 或 `Cmd/Ctrl + Shift + T`

## 文件操作

### 创建和打开

- **新建文件**：`Cmd/Ctrl + N`
- **打开文件**：**文件 → 打开文件...**（无默认快捷键）
- **快速打开**：`Cmd/Ctrl + O` — 跳转到最近、已打开或工作区中的文件
- **打开文件夹**：`Cmd/Ctrl + Shift + O`（工作区模式）

### 保存

- **保存**：`Cmd/Ctrl + S`
- **另存为**：`Cmd/Ctrl + Shift + S`
- **自动保存**：默认启用，可在设置中配置

### 导出

- **导出 HTML**：**文件 → 导出 → HTML** —— 生成一个文件夹，包含 `index.html`、`standalone.html` 和交互式 VMark 阅读器
- **导出 PDF**：**文件 → 导出 → PDF** —— 提供页面设置、字体、页码和侧边栏大纲；也可以使用打印（`Cmd/Ctrl + P`），在系统对话框中另存为 PDF
- **复制为 HTML**：`Cmd/Ctrl + Shift + C`

导出的 HTML 包含 VMark 阅读器，提供目录、设置面板等功能。[了解更多 →](/zh-CN/guide/export)

## 设置

使用 `Cmd/Ctrl + ,` 打开设置，可自定义：

- **外观**：主题、字体、字号、行高
- **编辑器**：自动保存间隔、默认行为
- **文件与图片**：资源管理、文档工具
- **集成**：AI 提供商、MCP 服务器
- **语言**：中日韩排版规则
- **Markdown**：导出选项、格式偏好
- **快捷键**：自定义键盘快捷键
- **终端**：终端字号和行高

## AI 写作辅助

VMark 内置 AI 精灵 —— 选中文字并按 `Mod + Y`，即可使用 AI 润色、扩展、翻译或转换你的文字。在 **设置 > 集成** 中配置你偏好的提供商。

[了解更多 AI 精灵 →](/zh-CN/guide/ai-genies) | [配置提供商 →](/zh-CN/guide/ai-providers)

## 入门技巧

1. **使用大纲导航**：点击大纲条目跳转到对应章节
2. **尝试专注模式**：`F8` 会淡化当前段落以外的所有内容
3. **边写边校验**：`Alt + Mod + V`（**视图 → 检查 Markdown**）运行 markdown lint 引擎和损坏链接检查
4. **学习快捷键**：完整参考见[快捷键指南](/zh-CN/guide/shortcuts)
