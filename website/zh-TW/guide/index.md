# VMark 快速入門

VMark 是人類與 AI 協作的純文字工作空間。雙方直接讀寫同一份產物 — markdown、YAML、JSON、TOML、Mermaid、SVG、HTML、程式碼 — 中間沒有任何轉譯層。當檔案是已知的產物（GitHub Actions 工作流程、`Cargo.toml`、`package.json`、`pyproject.toml`）時，VMark 會算繪出*對應的*檢視，而不是通用的 JSON 樹狀結構。

真正的差異不在於「能開啟更多檔案類型」— 每個 IDE 都做得到。而在於**結構感知預覽**：為每種產物提供結構化檢視，並搭配即時的原始碼窗格。

## 快速開始

1. 從[下載頁面](/zh-TW/download)**下載並安裝** VMark
2. **啟動應用程式**，立即開始寫作
3. 使用 **檔案 → 開啟檔案...** **開啟檔案**，或拖放任何[支援的格式](/zh-TW/guide/formats)（`Cmd/Ctrl + O` 是 **快速開啟**，用於跳到最近、已開啟或工作區中的檔案）
4. 使用 `Cmd/Ctrl + Shift + O` **開啟資料夾** 以進入工作區模式

## 介面概覽

### 主要區域

- **編輯器**：撰寫文件的主要區域
- **側邊欄**：檔案樹狀導覽（使用 `Ctrl + Shift + 2` 切換顯示）
- **大綱**：文件結構檢視（使用 `Ctrl + Shift + 1` 切換顯示）
- **狀態列**：字數統計、字元計數與自動儲存狀態（使用 `F7` 切換顯示）
- **終端機**：整合的 shell 面板（使用 `` Ctrl + ` `` 切換顯示）

### 選單列

- **檔案**：新增、快速開啟、最近使用的檔案與工作區、文件歷史紀錄、儲存、匯出、列印、關閉
- **編輯**：復原/取消復原、剪貼簿、尋找（包括在檔案中尋找）、選取、行操作、換行符號、精靈
- **格式**：文字樣式、標題、清單、引用區塊、文字轉換、中日韓文排版、文字清理、圖片清理
- **插入**：連結、圖片、影片、音訊、表格、程式碼區塊、數學、圖表、註腳、可折疊區塊、資訊方塊
- **檢視**：編輯器模式、窗格、側邊欄面板、專注/打字機模式、工具列、終端機、視窗狀態、檢查 Markdown、縮放
- **視窗**（macOS）：最小化、最大化、一致性明細、將全部移至最前
- **輔助說明**：VMark 輔助說明、鍵盤快捷鍵、`vmark` shell 指令（macOS）、回報問題

### 編輯模式

VMark 支援三種可切換的編輯模式：

| 模式 | 說明 | 快捷鍵 |
|------|------|--------|
| 富文字 | 所見即所得，即時格式預覽 | 預設 |
| 原始碼 | 帶有語法高亮的原始 Markdown | `F6` |
| 分割 | 左側為原始碼，右側為即時唯讀預覽 | `Shift + F6` |

### 檢視模式

利用以下檢視模式提升寫作專注度：

| 模式 | 說明 | 快捷鍵 |
|------|------|--------|
| 專注 | 高亮顯示當前段落 | `F8` |
| 打字機 | 保持游標置中 | `F9` |
| 自動換行 | 切換行換行 | `Alt + Z` |

## 基本格式

### 文字樣式

| 樣式 | 語法 | 快捷鍵 |
|------|------|--------|
| **粗體** | `**文字**` | `Cmd/Ctrl + B` |
| *斜體* | `*文字*` | `Cmd/Ctrl + I` |
| ~~刪除線~~ | `~~文字~~` | `Cmd/Ctrl + Shift + X` |
| `程式碼` | `` `code` `` | `Cmd/Ctrl + Shift + `` ` `` |

### 區塊元素

- **標題**：使用 `#` 符號或 `Cmd/Ctrl + 1-6`
- **清單**：以 `-`、`*`、`1.` 或 `- [ ]` 開頭建立任務清單
- **引言**：以 `>` 開頭，或使用 `Alt/Option + Cmd + Q`
- **程式碼區塊**：使用三個反引號並可指定語言
- **表格**：使用 **插入 → 表格** 或 `Cmd/Ctrl + Shift + T`

## 檔案操作

### 建立與開啟

- **新建檔案**：`Cmd/Ctrl + N`
- **開啟檔案**：**檔案 → 開啟檔案...**（無預設快捷鍵）
- **快速開啟**：`Cmd/Ctrl + O` — 跳到最近、已開啟或工作區中的檔案
- **開啟資料夾**：`Cmd/Ctrl + Shift + O`（工作區模式）

### 儲存

- **儲存**：`Cmd/Ctrl + S`
- **另存新檔**：`Cmd/Ctrl + Shift + S`
- **自動儲存**：預設啟用，可在設定中調整

### 匯出

- **匯出 HTML**：**檔案 → 匯出 → HTML** — 產生一個資料夾，內含 `index.html`、`standalone.html` 與互動式 VMark 閱讀器
- **匯出 PDF**：**檔案 → 匯出 → PDF** — 頁面設定、字型、頁碼與側邊欄大綱；或使用列印（`Cmd/Ctrl + P`），在系統對話框中另存為 PDF
- **複製為 HTML**：`Cmd/Ctrl + Shift + C`

匯出的 HTML 包含 VMark 閱讀器，具備目錄、設定面板等功能。[了解更多 →](/zh-TW/guide/export)

## 設定

使用 `Cmd/Ctrl + ,` 開啟設定進行自訂：

- **外觀**：主題、字型、字型大小、行距
- **編輯器**：自動儲存間隔、預設行為
- **檔案與圖片**：資產管理、文件工具
- **整合**：AI 供應商、MCP 伺服器
- **語言**：中日韓文排版規則
- **Markdown**：匯出選項、排版偏好設定
- **快捷鍵**：自訂鍵盤快捷鍵
- **終端機**：終端機字型大小與行距

## AI 寫作輔助

VMark 內建 AI 精靈 — 選取文字後按 `Mod + Y`，即可使用 AI 潤稿、擴寫、翻譯或改寫你的內容。在 **設定 > 整合** 中設定偏好的供應商。

[了解更多 AI 精靈 →](/zh-TW/guide/ai-genies) | [設定供應商 →](/zh-TW/guide/ai-providers)

## 入門提示

1. **使用大綱導覽**：點選大綱項目跳至對應章節
2. **嘗試專注模式**：`F8` 會讓當前段落以外的內容全部變淡
3. **邊寫邊驗證**：`Alt + Mod + V`（**檢視 → 檢查 Markdown**）執行 markdown lint 引擎與失效連結檢查
4. **學習快捷鍵**：完整參考請見[快捷鍵指南](/zh-TW/guide/shortcuts)
