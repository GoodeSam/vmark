# VMark 시작하기

VMark는 사람과 AI가 함께 작업하는 일반 텍스트 워크스페이스입니다. 양쪽 모두 마크다운, YAML, JSON, TOML, Mermaid, SVG, HTML, 코드 같은 동일한 결과물을 중간 변환 계층 없이 직접 읽고 씁니다. 파일이 알려진 결과물(GitHub Actions 워크플로, `Cargo.toml`, `package.json`, `pyproject.toml`)이라면 VMark는 일반적인 JSON 트리가 아니라 *그에 맞는* 보기를 렌더링합니다.

차별점은 "더 많은 파일 형식을 연다"는 것이 아닙니다 — 그건 모든 IDE가 합니다. 차별점은 **스키마 인식 미리 보기**입니다: 결과물마다 구조화된 보기를 제공하고, 실시간 소스 창과 짝을 이룹니다.

## 빠른 시작

1. [다운로드 페이지](/ko/download)에서 VMark를 **다운로드하여 설치** 합니다
2. **앱을 실행** 하고 바로 글쓰기를 시작합니다
3. **파일 → 파일 열기...**로 **파일을 열거나** [지원되는 형식](/ko/guide/formats)의 파일을 드래그 앤 드롭합니다 — `Cmd/Ctrl + O`는 최근 파일, 열린 파일, 워크스페이스 파일로 이동하는 **빠른 열기**입니다
4. 워크스페이스 모드를 위해 `Cmd/Ctrl + Shift + O`로 **폴더를 엽니다**

## 인터페이스 개요

### 주요 영역

- **에디터**: 문서를 작성하는 메인 영역
- **사이드바**: 파일 트리 탐색 (`Ctrl + Shift + 2`로 토글)
- **아웃라인**: 문서 구조 보기 (`Ctrl + Shift + 1`로 토글)
- **상태 표시줄**: 단어 수, 문자 수, 자동 저장 상태 (`F7`로 토글)
- **터미널**: 통합 셸 패널 (`` Ctrl + ` ``로 토글)

### 메뉴 바

- **파일**: 새로 만들기, 빠른 열기, 최근 파일 및 워크스페이스, 문서 기록, 저장, 내보내기, 인쇄, 닫기
- **편집**: 실행 취소/다시 실행, 클립보드, 찾기(파일에서 찾기 포함), 선택, 줄 작업, 줄 끝 문자, 지니
- **서식**: 텍스트 스타일, 제목, 목록, 인용문, 텍스트 변환, CJK 서식, 텍스트 정리, 이미지 정리
- **삽입**: 링크, 이미지, 동영상, 오디오, 표, 코드 펜스, 수식, 다이어그램, 각주, 접기 가능 블록, 정보 상자
- **보기**: 에디터 모드, 창, 사이드바 패널, 집중/타자기 모드, 도구 모음, 터미널, 창 상태, Markdown 검사, 확대/축소
- **창** (macOS): 최소화, 최대화, 정합성 내역, 모든 창 앞으로 가져오기
- **도움말**: VMark 도움말, 키보드 단축키, `vmark` 셸 명령 (macOS), 문제 신고

### 편집 모드

VMark는 세 가지 편집 모드 간에 전환할 수 있습니다:

| 모드 | 설명 | 단축키 |
|------|------|--------|
| 리치 텍스트 | 실시간 서식이 적용되는 WYSIWYG 편집 | 기본값 |
| 소스 | 구문 강조가 있는 원시 마크다운 | `F6` |
| 분할 | 왼쪽에 소스, 오른쪽에 읽기 전용 실시간 미리 보기 | `Shift + F6` |

### 보기 모드

다음 보기 모드로 글쓰기에 집중하세요:

| 모드 | 설명 | 단축키 |
|------|------|--------|
| 포커스 | 현재 단락 강조 | `F8` |
| 타이프라이터 | 커서를 중앙에 유지 | `F9` |
| 자동 줄 바꿈 | 줄 바꿈 토글 | `Alt + Z` |

## 기본 서식

### 텍스트 스타일

| 스타일 | 문법 | 단축키 |
|--------|------|--------|
| **굵게** | `**text**` | `Cmd/Ctrl + B` |
| *기울임꼴* | `*text*` | `Cmd/Ctrl + I` |
| ~~취소선~~ | `~~text~~` | `Cmd/Ctrl + Shift + X` |
| `코드` | `` `code` `` | `Cmd/Ctrl + Shift + `` ` `` |

### 블록 요소

- **제목**: `#` 기호 또는 `Cmd/Ctrl + 1-6` 사용
- **목록**: 줄을 `-`, `*`, `1.` 또는 작업 목록의 경우 `- [ ]`로 시작
- **인용문**: `>`로 시작하거나 `Alt/Option + Cmd + Q` 사용
- **코드 블록**: 선택적 언어와 함께 삼중 백틱 사용
- **테이블**: **삽입 → 표** 또는 `Cmd/Ctrl + Shift + T` 사용

## 파일 작업

### 생성 및 열기

- **새 파일**: `Cmd/Ctrl + N`
- **파일 열기**: **파일 → 파일 열기...** (기본 단축키 없음)
- **빠른 열기**: `Cmd/Ctrl + O` — 최근 파일, 열린 파일, 워크스페이스 파일로 이동
- **폴더 열기**: `Cmd/Ctrl + Shift + O` (워크스페이스 모드)

### 저장

- **저장**: `Cmd/Ctrl + S`
- **다른 이름으로 저장**: `Cmd/Ctrl + Shift + S`
- **자동 저장**: 기본적으로 활성화, 설정에서 구성 가능

### 내보내기

- **HTML 내보내기**: **파일 → 내보내기 → HTML** — `index.html`, `standalone.html`, 대화형 VMark Reader가 담긴 폴더
- **PDF 내보내기**: **파일 → 내보내기 → PDF** — 페이지 설정, 폰트, 페이지 번호, 사이드바 개요 제공. 또는 인쇄 (`Cmd/Ctrl + P`) 후 시스템 대화 상자에서 PDF로 저장
- **HTML로 복사**: `Cmd/Ctrl + Shift + C`

내보낸 HTML에는 목차, 설정 패널 등이 포함된 VMark Reader가 포함됩니다. [자세히 알아보기 →](/ko/guide/export)

## 설정

`Cmd/Ctrl + ,`로 설정을 열어 다음을 사용자 지정합니다:

- **모양**: 테마, 폰트, 폰트 크기, 줄 높이
- **에디터**: 자동 저장 간격, 기본 동작
- **파일 및 이미지**: 에셋 관리, 문서 도구
- **통합**: AI 제공자, MCP 서버
- **언어**: CJK 서식 규칙
- **마크다운**: 내보내기 옵션, 서식 기본 설정
- **단축키**: 키보드 단축키 사용자 지정
- **터미널**: 터미널 폰트 크기 및 줄 높이

## AI 글쓰기 지원

VMark에는 AI 지니가 내장되어 있습니다 — 텍스트를 선택하고 `Mod + Y`를 눌러 AI로 글을 다듬고, 확장하고, 번역하거나 변환할 수 있습니다. **설정 > 통합** 에서 원하는 제공자를 구성하세요.

[AI 지니에 대해 자세히 알아보기 →](/ko/guide/ai-genies) | [제공자 구성 →](/ko/guide/ai-providers)

## 시작을 위한 팁

1. **아웃라인으로 탐색**: 아웃라인 항목을 클릭하여 섹션으로 이동
2. **포커스 모드 사용**: `F8`은 현재 단락을 제외한 모든 것을 어둡게 만듭니다
3. **글을 쓰면서 검증**: `Alt + Mod + V` (**보기 → Markdown 검사**)는 마크다운 린트 엔진과 깨진 링크 검사를 실행합니다
4. **단축키 학습**: 전체 참조는 [단축키 가이드](/ko/guide/shortcuts)에 있습니다
