# VMark をはじめる

VMark は、人間と AI が協働するプレーンテキストのワークスペースです。両者は同じ成果物 — Markdown、YAML、JSON、TOML、Mermaid、SVG、HTML、コード — を、間に変換レイヤーを挟まずに直接読み書きします。ファイルが既知の成果物（GitHub Actions ワークフロー、`Cargo.toml`、`package.json`、`pyproject.toml`）である場合、VMark は汎用の JSON ツリーではなく、*その成果物にふさわしい*ビューを描画します。

差別化要因は「より多くのファイル形式を開けること」ではありません — それはどの IDE でもできます。**スキーマを理解したプレビュー**、つまり成果物ごとの構造化ビューと、ライブで連動するソースペインの組み合わせこそが違いです。

## クイックスタート

1. [ダウンロードページ](/ja/download)から VMark を **ダウンロードしてインストール** する
2. **アプリを起動** してすぐに執筆を開始する
3. **ファイル → ファイルを開く...** で **ファイルを開く** か、[対応している形式](/ja/guide/formats)のファイルをドラッグ＆ドロップする（`Cmd/Ctrl + O` は最近使ったファイル・開いているファイル・ワークスペースのファイルへ移動する **クイックオープン** です）
4. ワークスペースモードで `Cmd/Ctrl + Shift + O` で **フォルダを開く**

## インターフェースの概要

### メインエリア

- **エディタ**: ドキュメントを作成するメインの執筆エリア
- **サイドバー**: ファイルツリーナビゲーション（`Ctrl + Shift + 2` で切り替え）
- **アウトライン**: ドキュメント構造ビュー（`Ctrl + Shift + 1` で切り替え）
- **ステータスバー**: 単語数、文字数、自動保存状態（`F7` で切り替え）
- **ターミナル**: 統合シェルパネル（`` Ctrl + ` `` で切り替え）

### メニューバー

- **ファイル**: 新規、クイックオープン、最近開いたファイルとワークスペース、ドキュメント履歴、保存、エクスポート、印刷、閉じる
- **編集**: 元に戻す/やり直す、クリップボード、検索（ファイル内を検索を含む）、選択、行操作、改行コード、ジーニー
- **書式**: テキストスタイル、見出し、リスト、引用ブロック、テキスト変換、CJK フォーマット、テキストのクリーンアップ、画像のクリーンアップ
- **挿入**: リンク、画像、動画、音声、表、コードフェンス、数式、ダイアグラム、脚注、折りたたみブロック、情報ボックス
- **表示**: エディタモード、ペイン、サイドバーパネル、フォーカス/タイプライターモード、ツールバー、ターミナル、ウィンドウの状態、Markdown をチェック、ズーム
- **ウィンドウ**（macOS）: しまう、拡大/縮小、整合性の内訳、すべてのウィンドウを前面へ
- **ヘルプ**: VMark ヘルプ、キーボードショートカット、`vmark` シェルコマンド（macOS）、問題を報告

### 編集モード

VMark は 3 つの編集モードをサポートしており、切り替えることができます：

| モード | 説明 | ショートカット |
|--------|------|--------------|
| リッチテキスト | ライブフォーマット付きの WYSIWYG 編集 | デフォルト |
| ソース | シンタックスハイライト付きの生の Markdown | `F6` |
| 分割 | 左にソース、右に読み取り専用のライブプレビュー | `Shift + F6` |

### 表示モード

これらの表示モードで執筆に集中できます：

| モード | 説明 | ショートカット |
|--------|------|--------------|
| フォーカス | 現在の段落をハイライト | `F8` |
| タイプライター | カーソルを中央に固定 | `F9` |
| ワードラップ | 行の折り返しを切り替え | `Alt + Z` |

## 基本的なフォーマット

### テキストスタイル

| スタイル | 構文 | ショートカット |
|---------|------|--------------|
| **太字** | `**text**` | `Cmd/Ctrl + B` |
| *斜体* | `*text*` | `Cmd/Ctrl + I` |
| ~~取り消し線~~ | `~~text~~` | `Cmd/Ctrl + Shift + X` |
| `コード` | `` `code` `` | `Cmd/Ctrl + Shift + `` ` `` |

### ブロック要素

- **見出し**: `#` 記号または `Cmd/Ctrl + 1-6` を使用
- **リスト**: `-`、`*`、`1.`、またはタスクリストの場合 `- [ ]` で行を開始
- **引用**: `>` で始めるか `Alt/Option + Cmd + Q` を使用
- **コードブロック**: オプションの言語指定付きでトリプルバッククォートを使用
- **テーブル**: **挿入 → 表** または `Cmd/Ctrl + Shift + T` を使用

## ファイルの操作

### 作成と開く

- **新規ファイル**: `Cmd/Ctrl + N`
- **ファイルを開く**: **ファイル → ファイルを開く...**（デフォルトのショートカットなし）
- **クイックオープン**: `Cmd/Ctrl + O` — 最近使ったファイル・開いているファイル・ワークスペースのファイルへ移動
- **フォルダを開く**: `Cmd/Ctrl + Shift + O`（ワークスペースモード）

### 保存

- **保存**: `Cmd/Ctrl + S`
- **名前を付けて保存**: `Cmd/Ctrl + Shift + S`
- **自動保存**: デフォルトで有効、設定で変更可能

### エクスポート

- **HTML としてエクスポート**: **ファイル → エクスポート → HTML** — `index.html`、`standalone.html`、インタラクティブな VMark Reader を含むフォルダ
- **PDF としてエクスポート**: **ファイル → エクスポート → PDF** — ページ設定、フォント、ページ番号、サイドバーのアウトライン。または印刷（`Cmd/Ctrl + P`）からシステムダイアログの「PDF として保存」を使用
- **HTML としてコピー**: `Cmd/Ctrl + Shift + C`

エクスポートされた HTML には、目次、設定パネルなどを備えた VMark Reader が含まれます。[詳細を見る →](/ja/guide/export)

## 設定

`Cmd/Ctrl + ,` で設定を開いてカスタマイズできます：

- **外観**: テーマ、フォント、フォントサイズ、行の高さ
- **エディタ**: 自動保存間隔、デフォルトの動作
- **ファイルと画像**: アセット管理、ドキュメントツール
- **統合**: AI プロバイダー、MCP サーバー
- **言語**: CJK フォーマットルール
- **Markdown**: エクスポートオプション、フォーマット設定
- **ショートカット**: キーボードショートカットのカスタマイズ
- **ターミナル**: ターミナルのフォントサイズと行の高さ

## AI ライティング支援

VMark にはビルトインの AI Genie が搭載されています — テキストを選択して `Mod + Y` を押すと、AI で文章を磨いたり、拡張したり、翻訳したり、変換したりできます。**設定 > 統合** で好みのプロバイダーを設定してください。

[AI Genie について詳しく →](/ja/guide/ai-genies) | [プロバイダーの設定 →](/ja/guide/ai-providers)

## はじめてのヒント

1. **アウトラインでナビゲート**: アウトラインアイテムをクリックしてセクションにジャンプ
2. **フォーカスモードを試す**: `F8` で現在の段落以外を薄暗くする
3. **書きながら検証する**: `Alt + Mod + V`（**表示 → Markdown をチェック**）で Markdown Lint エンジンと壊れたリンクのチェックを実行
4. **ショートカットを学ぶ**: 完全なリファレンスは[ショートカットガイド](/ja/guide/shortcuts)にあります
